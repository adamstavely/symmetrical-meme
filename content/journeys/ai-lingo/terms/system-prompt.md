# System Prompt

## ID

system-prompt

## Track

2

## Order

20

## Part of speech

noun

## Pronunciation

SIS-tem prahmpt

## Definition

A standing set of instructions given to a model before the user ever types anything, defining its role, tone, rules, and boundaries. Users usually never see it, but it shapes every response.

## Usage

The tool refuses to discuss pricing because its system prompt instructs it to route those questions to sales.
