# Frontier

## ID

frontier

## Journey

3

## Order

37

## Part of speech

adjective, noun

## Pronunciation

frun-TEER

## Definition

Describing the most capable models currently in existence, or the small set of labs that produce them. “Frontier model” signals state of the art; “frontier lab” refers to the organizations pushing that edge.

## Usage

The task only needed a small, cheap model, not a frontier model, so the projected costs dropped by 90 percent.
