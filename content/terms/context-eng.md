## Pronunciation

## Definition

The discipline of managing everything a model sees at once: instructions, documents, retrieved data, conversation history, and tool outputs, all within the context window. The emerging successor to prompt engineering, reflecting that modern AI work is less about wording a single request and more about curating what the model knows when it answers.

## Usage

Prompt tweaks stopped helping; the real fix was context engineering, deciding which documents and history the assistant loads for each task.
