# Deterministic

## ID

deterministic

## Journey

2

## Order

30

## Part of speech

adjective

## Pronunciation

dih-tur-mih-NIS-tik

## Definition

Producing the same output every time for the same input. Traditional software is deterministic; LLMs generally are not, though settings can push them closer to it.

## Usage

The audit tool must be deterministic, so we use a fixed calculation there instead of a language model.
