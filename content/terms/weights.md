# Model Weights

## ID

weights

## Journey

1

## Order

15

## Part of speech

noun

## Pronunciation

MAH-dul WAYTS

## Definition

The final, learned values of a model's parameters after training. The weights effectively are the model: whoever has the weights can run the model.

## Usage

Releasing the model weights means anyone can download and run the model on their own hardware.
