# Agent

## ID

## Journey

4

## Order

62

## Part of speech

noun

## Pronunciation

AY-jent

## Definition

An AI system that can take actions on its own to accomplish a goal: it observes a situation, decides what to do, uses tools to do it, and checks the result. A chatbot answers; an agent acts.

## Usage

Instead of just drafting the reply, the agent looked up the account status, wrote the response, and queued it for approval.
